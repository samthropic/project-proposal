# Project Proposal - RepoIQ

## What and Why?

RepoIQ is a developer tool designed to help users understand unfamiliar codebases. One of the biggest issues developers face when joining a new project/team is understanding a large codebase, normally taking a significant amount of time, blocking them from writing code. Traditional methods of going file by file and attempting to map out a high-level overview can become overwhelming and cause confusion. 

RepoIQ would be a web application where the user can paste a GitHub repository link to the platform and recieve a visual and interactive representation of the codebase. The platform would analyze the repository and display the connections between files, functions, classes, fetaures, API's, and other important compoments.

## For Whom?

Users for RepoIQ include and arent limited to:
    - Software developers joining a new project at work
    - Students interning at a new company
    - Software developers contributing to an open source project
    - And much more!

## How?

Users would upload a GitHub repository, and RepoIQ would analyze its structure and generate an interactive map of the codebase.

From the map, users could:
    - View important files, functions, classes, and dependencies
    - See how different parts of the repository connect
    - Select a file or function to see what depends on it
    - Search the repository using simple questions such as “Where is authentication handled?”
    - Navigate directly from the visualization to relevant source code

## Scope

RepoIQ is fitting for a team of 4–6 developers because it can be divided into Github integration, code analysis, dependency mapping, visualization, search, and frontend/backend development.

To avoid making the project too ambitious, this version would support only one or two programming languages and would focus on clear relationships such as files, imports, functions, and classes rather than trying to fully understand every possible code dependency. Some features can be cut from the scope if needed.
